## الفحوص الجديدة المحددة قبل التنفيذ

1. C-195: HTTP لخروج مستخدم اصطناعي ثم محاولة استعمالCookie وCSRF القديمين عبر قارئات المستخدمين والتخصيصات والتنظيم والترقيم والتدقيق وكتابةتنظيمية، حتى عند تعذر تدقيقالخروج. المتوقعإبطالالوصول دوننتيجة أو تحويل أو كتابة/إيصال، وتدويرCookie إلىجلسةمجهولة جديدة. لا يعتمد على فحصالخدمة وحده.
2. C-196: جولة HTTP فعلية علىmadartest لمسار حساب اصطناعي من إنشائه وتغيير المؤقتة، ثم تخصيص صلاحيات وإبطال جلسته، وتفرد إعداد سلسلة برقمينمتزامنين وتعارض نسخة. الجرد والحارس والملكية والتنظيف إلزامية؛ لا تعاد حالاتC-194 الناجحة دونسبب.
3. مراجعةقراءة للنشرالحالي: الحزمة والجاهزية ورفضAPI دوندخول، ثم المتصفح إن توافرتجلسة مناسبة. تسجل نسخةالنشر كماهي؛ لا يفترض أنهامرشحC-194 ولا تجرى كتابةاختبارفيالإنتاج.
