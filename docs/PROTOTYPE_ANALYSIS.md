# تحليل نموذج مدار

## النتيجة ونطاق البداية

الملف المرفق نموذج تفاعلي عربي لإدارة الموارد البشرية، يوضح الثيم والتنقل وعددًا من الإجراءات التجريبية. يتكون من HTML وCSS وJavaScript داخل ملف واحد، ويحفظ الحالة محليًا في المتصفح. تحويل الفكرة إلى نظام فعلي يحتاج بناء البيانات والصلاحيات وقواعد العمل وفق المتطلبات المتفق عليها.

اسم النظام المعتمد **مدار**، والاستخدام لمنشأة المستخدم وفروعها فقط. البداية المعتمدة: **الموظفون والإجازات والموافقات والرواتب**. وصلت التقنيات واعتمدت في [المتطلبات التقنية](TECHNICAL_REQUIREMENTS.md)، ومنها TiDB Cloud وواجهة تدعم العربية والإنجليزية وPWA والمراكز المشتركة. يظل هذا التحليل وصفًا للنموذج الأصلي؛ تفاصيل التنفيذ وحالات المهام محفوظة في [خطة العمل](../WORK_PLAN.md).

## الثيم وعناصر الواجهة

- اللغة عربية واتجاه الصفحة RTL. الخط Almarai مضمّن في الملف بصيغة WOFF2، ومعه نص ترخيص الخط؛ يلزم الاحتفاظ بإشعاراته عند إعادة استخدامه.
- اللون الرئيسي أخضر مزرق `#087b7a` ودرجته الداكنة `#006362`، مع خلفيات فاتحة وألوان زرقاء رمادية وبطاقات ذات شفافية وحدود دائرية.
- شريط جانبي وأيقونات وقوائم فرعية، وشريط علوي للسياق والبحث والإشعارات، ومساحة رئيسية تتغير بحسب القسم.
- عناصر متكررة: جداول وفلاتر وترقيم صفحات، شارات حالات، نوافذ حوار للنماذج والتفاصيل، تنبيهات قصيرة، تبويبات وبطاقات وتقويم.
- توجد قواعد CSS للاستجابة لأحجام الشاشة، وعناصر مساعدة للوحة المفاتيح والتركيز ووسوم ARIA. فاعليتها البصرية وسهولة القراءة على الجوال تحتاج مراجعة أثناء تنفيذ الثيم.

مواضع اسم «مدار حديقة الوطن» تشمل عنوان الصفحة والشعار والبحث والتذييل والنصوص المساعدة. تُراجع عند بناء هوية التطبيق باسم «مدار» ضمن مهمة الثيم، بدل تعديل المرجع الأصلي.

## البنية التقنية الموجودة

التنقل قائم على جزء الرابط بعد `#`، وتُنشأ الواجهات بقوالب JavaScript. الحالة تقرأ وتكتب في `localStorage` تحت المفتاح `madar-hr-showcase-v1`. يتضمن الملف بيانات بداية افتراضية ومستخدمًا ثابتًا، وتُجرى القرارات والحسابات داخل المتصفح.

لا يتضمن الملف خادم تطبيق أو مخطط قاعدة بيانات أو دخولًا حقيقيًا أو فرضًا للصلاحيات على الخادم. لا تظهر استدعاءات `fetch` أو `XMLHttpRequest` أو `WebSocket` أو ملفات JavaScript خارجية في المصدر. هذا يصف الملف نفسه، ولا يثبت وجود أو عدم وجود أنظمة أخرى لدى المنشأة.

بعض الصفحات الفرعية تقرأ صفوفًا من `sampleBranchData`، وبعضها يشتق نتائج من الحالة المحلية، وبعض الروابط يعيد فتح الواجهة الرئيسية للقسم. البيانات التجريبية لا تُعتمد كبيانات منشأة أو سياسات رواتب وإجازات.

توجد معالجة للهروب من محارف HTML في القوالب ومعالجة لبعض بدايات صيغ CSV. هذه ملاحظات من المصدر، وليست تقييمًا أمنيًا أو تحققًا من نظام إنتاج.
