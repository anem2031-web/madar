## البنية والبيانات

الحزمة HTML وCSS وJavaScript تقليدي، وليست مشروع React أو خادم أعمال. تحمل خمسة سكربتات defer بالترتيب catalog ثم branch-views ثم dashboard ثم approvals ثم app؛ تتشارك التعريفات والحالة، ويبدأ app.js الرسم مباشرةً.

الجرد الثابت:14صفحة رئيسية،75مدخل صفحة فرعية،33أيقونة،14عائلة طلبات. عدد المداخل ليس عدد وحدات إنتاج مستقلة؛ كثير منها قوالب عامة وبيانات نموذجية. يستخدم التوجيه hash، ويختبر أسماء الصفحات فقط؛ لا حارس صلاحيات أو مصادقة فعلي. الرأس يعرض شخصية نموذجية ثابتة.

الحالة تُحفظ في localStorage تحت `madar-hr-showcase-v1`، ومن ضمنها الموظفون ورواتبهم وأرصدتهم وطلباتهم. لا توجد معاملات خادم أو تدقيق مركزي أو تزامن مستخدمين. preview.mjs يقدم قائمة ملفات محصورة عبر GET/HEAD على127.0.0.1، وليس بديلًا عن Express/tRPC/TiDB.

من أمثلة قواعد الأعمال التجريبية التي تتعارض مع قرارات مدار أو لم تُعتمد: ترقيم الموظف max+1 آليًا، وتعديل الحالة والرصيد والراتب في النموذج نفسه، وأرصدة24/30يومًا و8ساعات، وخصم السنوية محليًا عند الاعتماد، وحساب الراتب الأساسي+10%−5%. صفحات التكاملات والأدوات الذكية محاكاة وتنقل محلي، وليست خدمات ربط أو ذكاء منفذة.

لم ترصد مراجعة المصدر المحدودة fetch/XHR/WebSocket/sendBeacon أو eval/new Function أو سكربتات خارجية أو Cookies/Service Worker. الأصول محلية. يستخدم الرسم innerHTML وinsertAdjacentHTML ومعالجات document؛ توجد دالة escape لكن بعض الأدوات تقبل HTML جاهزًا. هذه ملاحظة دمج تستدعي عقودًا مناسبة، وليست إعلان ثغرة مثبتة أو تدقيق أمني شامل.

## حد النقل المقترح — غير منفذ

1. نقل بنية الغلاف والشعار وهندسة الأيقونات والرموز والمقاسات والشفافية وسلوك الشريط إلى مكونات React القائمة، مع مراجعة cascade حتى آخر ملف CSS، وإزالة القواعد المستبدلة ضمن مهمة التنفيذ.
2. اشتقاق روابط كل مستوى من سجل الحارس والصلاحيات الفعلية. تبقى الجلسة وAuthScreen ومفاتيح الصفحات وتوجيه الروابط المحمية وtRPC والتدقيق والخادم مصادر الحقيقة الحالية.
3. ترجمة النصوص ومعالجة الاتجاه بأسماء وخصائص منطقية، والتحقق من التركيز واللمس وحفظ المسودات. لا يُحمّل app.js الذي يستبدل DOM ويهيئ الحالة التجريبية داخل التطبيق.
4. مقارنة الواجهة على أحجام وحالات متكافئة، بما فيها الشريط المطوي والموسع واللمس واللغتان وتقليل الحركة/الشفافية. توثيق المقاسات والفروق الفعلية؛ لا نسبة كلية مختلقة.

نقل غلاف التصميم وربطه بالوحدات القائمة يختلف عن بناء بطاقات الرئيسية وتقويمها والبحث والإشعارات وبقية الوظائف. نطاق هذه الوظائف وبياناتها وصلاحياتها يحتاج توجيه المستخدم وخطته قبل التنفيذ؛ وجودها في ZIP لا يعتمدها تلقائيًا. لا جداول أو ترحيل أو اعتماد جديد يتطلبه تحليل الثيم نفسه.
