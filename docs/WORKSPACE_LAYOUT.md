## النطاق ومعايير القبول

- غلاف مشترك بعرض النافذة للصفحات المخولة ومساحة العمل الحالية `/`، دون max-width عام أو بطاقة دخول تحيط بصفحات الإدارة. تبقى أقصى عروض نماذج الوحدات وتمرير جداولها الداخلي لسهولة القراءة.
- سايدبار على جهة البداية: يمين العربية ويسار الإنجليزية. من 1024px يظهر ثابتًا في التخطيط مع طي صريح للأيقونات، وتحته درج جوال/تابلت بعنوان وزر إغلاق وEscape وعودة تركيز. يفتح بالضغط لا hover، ويغلق عند التنقل والخروج وفقد الحالة المخولة والانتقال لحجم سطح المكتب حتى لا يترك الصفحة inert.
- روابط مساحة العمل والصفحات الخمس المنفذة فقط، عبر سجل الحارس وgetAllowedLandingPages وصلاحيات الجلسة الفعلية، مع aria-current للصفحة النشطة. لا اختصار بصلاحية الدور أو تجاوز لمدير النظام، ولا إحصاءات أو بحث أو إشعارات أو صفحات موظفين/إجازات/رواتب وهمية.
- رأس واضح للسياق والهوية وتبديل اللغة، وهوية الحساب ودوره وخروج فعلي من المسار الحالي. الأيقونات SVG من الكود بأسماء وصول مترجمة؛ تعكس الأسهم الاتجاهية فقط. لا قائمة حساب شكلية أو وظائف جديدة.
- الحفاظ على غلاف عام مناسب للدخول والكلمة المؤقتة والتحقق والنهايات الآمنة وإفصاح إعادة التعيين الذاتي المعزول، دون سايدبار أو بيانات خاصة قديمة. قرار الحارس الحالي يختار الغلاف؛ لا يختار من pathname وحده.
- يبقى AuthScreen المالك الوحيد للجلسة والحارس، وتبقى مفاتيح PageView الحالية username:pageID. تغيير اللغة أو طي القائمة أو فتح الدرج لا يعيد تركيب النموذج أو يرسل حفظًا. يبقى التحقق الخلفي مانعًا للأفعال والتنقل وفق العقد الحالي مع حفظ المسودة، ولا تتحول هذه الدفعة إلى تغيير أمن أو قواعد أعمال.
- ألوان المرجع ورموزه الدلالية مع نص 14–16px وهدف لمس 44px والتفاف عند320px، وتركيز مرئي وتقليل الحركة. يعاد استخدام خطي Almarai العادي400 العربي واللاتيني المضمنين في HTML وترخيص SIL OFL، كأصول محلية مجمعة دون طلبات خارجية أو أوزان أو اعتماد جديد. لا يمس ملف المرجع الأصلي أو بياناته التجريبية.

طي القائمة اختيار داخل الجلسة فقط، دون تفضيل جديد محفوظ. لا جداول أو حقول أو API أعمال أو صلاحيات أو سلاسل أرقام أو متغيرات جديدة. لا استعلامات أو فهارس جديدة؛ تظل استعلامات الوحدات وتدقيقها وحدود قياسها القائمة. التنقل يمر بالوحدات المخولة وتستمر قراءاتها المعتادة المدققة، ولا حدث أعمال عن فتح/طي الغلاف نفسه.

## المسؤوليات

- `client/src/app/layouts/`: الغلاف العام، وغلاف مساحة العمل، والتنقل/درج الجوال والهوية والأيقونات وعقودها. النصوص العامة في shared/i18n/ar وen؛ تسميات الصفحات المستمدة من الوحدات تُجمع بتعريف شامل مقابل ProtectedPageId.
- App يبقي اللغة وDirectionProvider وتأثير الاتجاه، ويمرر تبديل اللغة. AuthScreen يستعمل الغلاف المناسب بعد قراراته الحالية دون نقل المصادقة أو الحارس أو إنشاء سياق وصول ثانٍ.
- `client/src/styles/`: رموز وأسلوب الغلاف الجديد وإزالة قواعد الغلاف الإداري والتنقل التي استبدلت. خطا المرجع في أصول أنماط محلية تستوردهما Vite كملفات ذات بصمة، مع ترخيص متاح كنص عام؛ تضاف خدمة ملف الترخيص الثابت فقط عند الحاجة ضمن الملفات العامة، لا صفحة وحدة جديدة.
- الاختبارات تفحص الأسماء والروابط والاتجاه والمكونات عبر React DOM server وVitest القائمة؛ لا مكتبات اختبار أو أيقونات أو Drawer إضافية.

## التحقق وحدود PWA

يتحقق من ADMIN وHR ومنح مستقل ومنع/غياب الروابط، والصفحة النشطة وblocked، وحالات الدخول والمؤقت وعدم وجود صفحة وفشل التحقق والخروج وإعادة التعيين المعزولة. متصفح معزول ببيانات منفصلة يختبر العربية والإنجليزية بعروض320 و390 و768 و1024 و1440، والطي ودرج الجوال وEscape وعودة التركيز وإغلاقه عند تغيير الحجم/التنقل، وحفظ مسودة غير سرية عند تغيير اللغة والطي، واحتواء الجدول وعدم تمدد الصفحة. تبقى الأسرار خارج اللقطات والسجل والتوثيق.

يلزم TypeScript وVitest والبناء وNode24 وفحص روابط الوثائق وتنظيف الأصول والاستدعاءات الميتة ذات الصلة. لا تجارب كتابة أو تغييرات حسابات على إنتاج المنشأة؛ لا يعاد فحص المراكز المقبولة دون تغيير يبرره.

تبقى manifest وSW وسياسة تخزين صفحة الانقطاع وحدها كما هي مع اختبارات التراجع. لا install prompt أو update banner أو skipWaiting أو إعادة تحميل قسرية أو حفظ أعمال دون اتصال في هذه الدفعة. اختبار Android/iPhone الفعلي والتثبيت والفتح والانقطاع والخصوصية وتحديث نسختين مع تبويبين ومسودة ينتظر الأجهزة وبيئة اختبار نسخة مضبوطة مصرحًا بها؛ لا موعد متفق عليه، ولا تثبته محاكاة العرض. يسلم الهيكل لقبول مستقل قبل دفعة M3-06 التالية.
