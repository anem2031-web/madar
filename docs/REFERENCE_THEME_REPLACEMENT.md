- شريط المصدر المطوي76px، والتمدد إلىmin(228px,48vw) بالتحويم أو التركيز المرئي فوق المحتوى، دون إعادة توزيع العمود؛ تطبيق الزجاج والتمويه والحدود والشعار وهندسة الأيقونات نفسها. يدعم فقد التحويم وتقليل الحركة والشفافية حسب المصدر. وضع اللمس يستخدم درج270px/86vw مع الحفاظ على native dialog وإغلاقه وتركيزه والخروج الآمن؛ خصائص الموضع تُعكس للإنجليزية. يقاس اختيار الوضع وفق any-hover كما في المصدر، ولا يدعى اختبار لمس فعلي من محاكاة العرض وحدها.
- تنظيم القائمة بأسلوب مجموعات المصدر وقائمتها الفرعية المجاورة للشريط في وضع المؤشر، وداخل درج اللمس عند فتحه. تظل مساحة العمل والفروع روابط مباشرة، وتجمع صفحات الإدارة المنفذة في قائمة إدارة النظام عند توفر أي صلاحية لها. كل رابط فرعي وظهور المجموعة مشتق من سجل الحارس ومنح الجلسة الفعلية؛ لا روابط مستقبلية أو منح جديدة. تسميات المجموعات مترجمة.
- نقل أحجام النص المصدرية ووزن400، واللون الرئيسي#087b7a، والرأس الزجاجي ومقاساته وحواشي المحتوى. تستخدم ملفات Almarai والترخيص القائمة المطابقة للمصدر. الصفحات الحالية تستعمل أسطح المصدر بدل الغلاف الأبيض العام المفروض على كل صفحة. يبقى اسم البرنامج مدار/Madar وتسميات وظائفه المعتمدة، وهوية الحساب الفعلية وتبديل اللغة والخروج، ضمن الرأس المناسب.
- الاحتفاظ بمنطق النماذج والصفحات والحالة ومفاتيحها ومكوّنات الأخطاء والحارس والجلسة الحالية؛ تغيير التصميم أو اللغة أو فتح قائمة لا يعيد تركيب النموذج أو يحفظه. الغلاف العام للدخول والمؤقت وإعادة التعيين المعزولة والنهايات الآمنة يبقى منفصلًا عن غلاف الحساب المخوّل.
- الاقتصار على وظائف وصفحات مدار المنفذة. بطاقة الحساب الحالية تعاد تنسيقها؛ لا بناء لوحة أرصدة أو رواتب أو تقويم أو بحث أو إشعارات أو بيانات نموذجية أو إعادة تسميتها كوظائف حقيقية.

## المسؤوليات والعقود

- `client/src/app/layouts/`: الشعار والأيقونات والتنقل المتدرج والغلاف وحالات فتحه وتركيزه. العقد الخارجي لـWorkspaceLayout وقرار AuthScreen للجلسة والحارس ثابتان.
- `client/src/styles/`: رموز وتنسيق المرجع المستعملة فعليًا. تُفصل الملفات إن لزم وفق وظيفة التنسيق، وتستورد من main.css؛ لا نسخ CSS للوحدات غير المبنية أو سكربتات العرض التجريبية.
- `shared/i18n/ar/shell.ts` و`en/shell.ts`: النصوص اللازمة للتنقل الحالي فقط، وتنظيف مفاتيح الطي اليدوي التي أزيل سلوكها.
- اختبارات `server/core/permissions/` الحالية: اشتقاق الروابط من السجل لكل مجموعات الصلاحيات، والربط بين الغلاف وقرار الحارس، والتعطيل والاتجاه واللغة. تراجع وفق سلوك القائمة الجديد، دون إضافة اعتماد اختبار.
- لا خادم أو API أو استعلام أو مخطط أو ترحيل أو إذن أو نطاق بيانات أو سلسلة ترقيم جديد؛ الاستعلامات والفهارس والتدقيق الحالي للوحدات كما هي. فتح القائمة وتحويل شكلها ليس حدث أعمال مستقلًا. لا تغيرات env أو حزم أو PWA أو CHECK أو بيانات منشأة.

قال المستخدم «مناسب جدا الان التالي ايش» بعد بيان القياسات والفروق وحالة التصحيح. اعتُمد التصميم والفروق الموضحة، ولا يعاد طلب قبولهما. يبقى نشر C-157 والتحقق منه وفحصHR وبوابةPWA؛ لم تُنفذ هذه الأعمال من هذا الرد ولا يُعد قبول التصميم إنهاءً لـM3-06. الترتيب المباشر نشر التصحيح وفحصه، ثم بقيةM3-06 وتحقق الأساسM3-07 قبل ملف الموظفM4-01. لم يُغير هذا التوثيق كودًا أو قاعدة أو حالة نشر أو نتيجة اختبار.
